# GPoliciesT

GPoliciesT is a Retrieval-Augmented Genrative (RAG) chatbot meant to help understand it's database of policies, which is currently the policies of the University of Richmond. It also uses a postgres server to remember the conversation.

## How to Use

1. Rename .env.example to .env and replace the empty fields to your API keys/info.

2. Run `docker compose up` in the root directory GPoliciesT

3. Open http://localhost:5173/ for the application.
